# Privacy Policy for GitHub HTML Preview

Effective date: September 25, 2026

GitHub HTML Preview does not collect, transmit, sell, or share personal information or user data. It does not use analytics, telemetry, advertising, tracking, or an external service or backend operated by the extension developer.

When you choose to preview an HTML file, the extension processes that file and its referenced repository assets locally in your browser. It may request those files directly from `github.com` or `raw.githubusercontent.com` using your existing GitHub browser session. This is required only to provide the preview feature. Those requests are subject to GitHub's own privacy practices.

The selected HTML source and information needed to render it may be placed temporarily in Chrome's session-only extension storage so it can be passed to the preview tab. The extension removes that temporary entry after the preview retrieves it. The extension does not retain a browsing history or send this content to the developer or any third party.

The extension does not access or store your GitHub password, authentication tokens, cookies, or payment information. It does not request Chrome's `cookies` permission.

If you have questions about this policy, open an issue at <https://github.com/deanjiang/github-html-preview/issues>.
